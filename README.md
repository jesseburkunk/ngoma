# Ngoma

Tuned world percussion. A browser groovebox with synthesized, tunable hand percussion
(surdo, tumba, djembe, conga, bongo, darbuka, agogô, clave, shaker), rhythm presets by
tradition, polymeter, light reverb and delay, and loop export (WAV + dry WAV + MIDI + JSON).

## Deploy to Cloudflare Pages

    ./deploy.sh

First run opens the browser to log in to Cloudflare and creates the Pages project `ngoma`.
After that every run publishes `public/` as the new production version.
Requires Node.js (`brew install node`).

## Structure

- `public/index.html`: the whole app (HTML, CSS, JS in one file). Source of truth.
- `public/_headers`: HTTP headers for Cloudflare Pages.
- `wrangler.toml`: Pages config.
- `deploy.sh`: login, create project on first run, deploy.

## Code layout inside index.html

- ENGINE: instruments, presets, pattern generation, variation, polymeter, event list per step.
  Pure JS without DOM or audio, intended to move to a Max for Live device later.
- AUDIO: Web Audio voices, reverb (generated impulse response), tape-style delay, graph.
- UI: knobs, lanes, controls.
- EXPORT: offline render with the tail folded back for seamless loops, MIDI writer, zip writer.

## Roadmap

1. Web prototype (this).
2. Max for Live device reusing the engine, MIDI out to a Drum Rack and/or own sound.
3. Optional VST3/AU in JUCE.

Open: save/load own patterns, MIDI import, test in real tracks.

## Worp (public/worp)
Chance synth for pads and leads, after the Cyma Forma RND idea: one button throws a new sound of up to four layers (Supersaw, FM, Wavetable, Air) with a modular web of modulation that keeps re-patching itself, up to two effects after unusual modules (4ms SMR, Xaoc Lipsk, Make Noise Mimeophon, Mutable Rings, Bode frequency shifter, Qu-Bit Nautilus), a master filter with Ngoma's four models, mix and mute per layer, the last 8 throws, playing by itself (drone or phrase) and MIDI (Chrome/Edge). Its engine is inlined in Ngoma as the block 'Worp engine for Ngoma'; never edit that block by hand, change Worp and deploy.
